# 💰 فین‌ترک | مدیریت مالی شخصی

**فین‌ترک** یک برنامه تحت وب فارسی برای ثبت درآمد و هزینه، برنامه‌ریزی بودجه و بررسی گزارش‌های مالی ماهانه است. هدف پروژه ارائه تصویری ساده و قابل‌فهم از جریان پول و عادت‌های مالی روزمره است.

> این نرم‌افزار ابزار ثبت و تحلیل دستی اطلاعات مالی است و به حساب بانکی یا درگاه پرداخت متصل نمی‌شود.

## ✨ امکانات

- 📊 داشبورد خلاصه درآمد، هزینه و موجودی خالص ماه جاری
- ➕ ثبت درآمد و هزینه با عنوان، مبلغ، تاریخ، دسته‌بندی و یادداشت
- 🔎 جست‌وجو و فیلتر تاریخچه تراکنش‌ها
- 🧾 دسته‌بندی جداگانه برای درآمدها و هزینه‌ها
- 🎯 تعریف بودجه ماهانه برای دسته‌های هزینه و مشاهده میزان مصرف
- 📈 گزارش ماهانه و سهم هر دسته از هزینه‌ها
- 📱 رابط کاربری فارسی، راست‌چین و واکنش‌گرا
- 🔐 استفاده از PDO، کوئری آماده، پاک‌سازی خروجی و توکن CSRF

## 🚀 راه‌اندازی سریع

۱. مخزن را دریافت کنید:

```bash
git clone https://github.com/dyfiydkyckg-create/FinTrack.git
cd FinTrack
```

۲. فایل `database/schema.sql` را در MySQL اجرا کنید.

۳. اطلاعات اتصال پایگاه داده را از طریق متغیرهای محیطی تنظیم کنید. نام متغیرها در `.env.example` آمده است.

۴. سرور توسعه PHP را اجرا کنید:

```bash
php -S localhost:8000
```

۵. در مرورگر به `http://localhost:8000` بروید.

راهنمای کامل در [مستندات نصب](docs/INSTALLATION.md) قرار دارد.

## 🗃️ مدل داده

- **categories:** دسته‌بندی‌های درآمد و هزینه
- **transactions:** تراکنش‌ها، مبلغ، تاریخ و یادداشت
- **budgets:** سقف بودجه هر دسته در هر ماه

## 🔒 ملاحظات امنیتی

- دسترسی به پایگاه داده از طریق PDO و Prepared Statement انجام می‌شود.
- خروجی‌های پویا با تابع `e()` پاک‌سازی می‌شوند.
- فرم‌های تغییردهنده داده از توکن CSRF استفاده می‌کنند.
- فایل حاوی اطلاعات محرمانه نباید به مخزن عمومی اضافه شود.
