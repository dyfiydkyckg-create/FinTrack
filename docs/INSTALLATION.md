# راهنمای نصب و راه‌اندازی فین‌ترک

این راهنما مراحل اجرای محلی فین‌ترک را توضیح می‌دهد.

## پیش‌نیازها

- PHP نسخه ۸.۱ یا بالاتر
- MySQL نسخه ۸ یا MariaDB سازگار
- افزونه‌های PHP شامل `pdo_mysql` و `mbstring`
- وب‌سرور Apache یا Nginx؛ برای توسعه می‌توان از سرور داخلی PHP استفاده کرد.

## ۱. دریافت پروژه

مخزن را دریافت کرده و وارد پوشه پروژه شوید:

```bash
git clone https://github.com/dyfiydkyckg-create/FinTrack.git
cd FinTrack
```

## ۲. ساخت پایگاه داده

فایل `database/schema.sql` را در ابزار مدیریت MySQL اجرا کنید. این فایل پایگاه داده، جدول‌های تراکنش‌ها، دسته‌بندی‌ها و بودجه‌ها و دسته‌بندی‌های اولیه را می‌سازد.

برای نمونه با خط فرمان:

```bash
mysql -u root -p < database/schema.sql
```

## ۳. تنظیم اتصال

مقادیر نمونه در فایل `.env.example` قرار دارند. متغیرهای محیطی PHP را با اطلاعات پایگاه داده خود تنظیم کنید:

- `DB_HOST`: نشانی میزبان
- `DB_PORT`: درگاه MySQL
- `DB_NAME`: نام پایگاه داده
- `DB_USER`: نام کاربری
- `DB_PASS`: گذرواژه
- `APP_CURRENCY`: واحد پول نمایشی

در محیط محلی، در صورت نیاز می‌توانید مقادیر پیش‌فرض اتصال را در `config/database.php` تغییر دهید. فایل حاوی گذرواژه واقعی را وارد مخزن عمومی نکنید.

## ۴. اجرای محلی

از ریشه پروژه دستور زیر را اجرا کنید:

```bash
php -S localhost:8000
```

سپس نشانی `http://localhost:8000` را در مرورگر باز کنید.

## ۵. بررسی اولیه

1. داشبورد را باز کنید.
2. یک درآمد و یک هزینه آزمایشی ثبت کنید.
3. نمایش ارقام در داشبورد و فهرست تراکنش‌ها را بررسی کنید.
4. برای یک دسته هزینه بودجه تعریف کنید.
5. گزارش ماه را مشاهده کنید.

## نکات امنیتی و انتشار

- از گذرواژه قوی و کاربر پایگاه داده با حداقل دسترسی لازم استفاده کنید.
- در محیط عملیاتی، HTTPS را فعال کنید و خطاهای داخلی PHP را به کاربر نمایش ندهید.
- فایل‌های پیکربندی محرمانه و نسخه پشتیبان پایگاه داده را عمومی نکنید.
- پیش از استفاده واقعی، پشتیبان‌گیری و آزمون بازیابی را تنظیم کنید.
- این نسخه ابزار ثبت و گزارش شخصی است و به حساب بانکی متصل نمی‌شود.

## عیب‌یابی

- **خطای اتصال:** فعال بودن MySQL، نام پایگاه داده و متغیرهای اتصال را بررسی کنید.
- **خطای درایور PDO:** افزونه `pdo_mysql` را نصب و در PHP فعال کنید.
- **نمایش نادرست فارسی:** کدگذاری پایگاه داده و اتصال را روی `utf8mb4` قرار دهید.
- **ثبت نشدن فرم:** درخواست باید از طریق POST ارسال شود و نشست مرورگر فعال باشد.
