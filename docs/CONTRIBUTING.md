# راهنمای مشارکت در فین‌ترک

از علاقه شما به بهبود فین‌ترک سپاسگزاریم.

## روند پیشنهادی

1. مخزن را Fork کنید.
2. برای تغییر خود یک شاخه با نام روشن بسازید؛ مانند `feature/monthly-export` یا `fix/budget-calculation`.
3. تغییرات را کوچک، متمرکز و قابل بررسی نگه دارید.
4. پیام Commit را کوتاه و توصیفی بنویسید.
5. پیش از ارسال Pull Request، تغییرات را در محیط محلی بررسی کنید.
6. در توضیح Pull Request هدف، روش آزمون و تصاویر رابط کاربری (در صورت نیاز) را درج کنید.

## استانداردهای کدنویسی

- نام متغیرها و توابع باید معنادار و یکدست باشند.
- برای کوئری‌های پایگاه داده از Prepared Statement استفاده کنید.
- خروجی‌های پویا را پیش از نمایش با تابع امن‌سازی خروجی پاک‌سازی کنید.
- عملیات تغییردهنده داده باید اعتبارسنجی سمت سرور و محافظت CSRF داشته باشند.
- رابط کاربری باید فارسی، راست‌چین و واکنش‌گرا باقی بماند.
- اطلاعات محرمانه، گذرواژه و داده شخصی واقعی را Commit نکنید.

## گزارش مشکل یا پیشنهاد

در گزارش خود نسخه PHP و MySQL، مراحل بازتولید، نتیجه مورد انتظار و نتیجه مشاهده‌شده را بنویسید. برای مشکلات ظاهری، تصویر یا اندازه صفحه را نیز اضافه کنید.

## پیش از ارسال

- [ ] کد از نظر خطاهای نحوی بررسی شده است.
- [ ] سناریوی اصلی تغییر به‌صورت دستی آزموده شده است.
- [ ] متن‌ها و راهنمایی‌های رابط کاربری فارسی هستند.
- [ ] مستندات مرتبط به‌روزرسانی شده‌اند.
